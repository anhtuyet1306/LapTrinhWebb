# Buổi 2 - Tìm kiếm bài viết
## Đối tượng dữ liệu
Bài viết trong website tin tức của Khoa.
## Chức năng
- Nhập từ khóa tìm kiếm bài viết
- Tìm kiếm bài viết theo tiêu đề
- Hiển thị tiêu đề, tác giả và chuyên mục
- Hiển thị danh sách kết quả tìm kiếm
- Thông báo khi không tìm thấy bài viết
## Công nghệ
- HTML
- PHP
## Cách chạy
1. Mở XAMPP.
2. Chạy Apache.
3. Truy cập:
   http://localhost/LapTrinhWeb/Buoi02/
